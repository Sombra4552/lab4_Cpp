## Задание 1

### Текст задачи

Реализовать определение класса "LineSegment" (отрезок на координатной прямой). 
Поля класса: "double x", "double y" (координаты начала и конца отрезка). 
Необходимо реализовать:
- Не менее трех конструкторов (по умолчанию, с параметрами, копирования).
- Перегрузку оператора вывода "<<" для вывода полей.
- Метод "Contains(double value)", который определяет, попадает ли заданное число в отрезок. Результат должен быть типа "bool".
Протестировать все методы, включая конструкторы. Все исходные данные должны вводиться с клавиатуры с обязательной проверкой на корректность.

### Алгоритм решения

1. В заголовочном файле "line_segment.h" объявить класс "LineSegment" с приватными полями "x_" и "y_".
2. Объявить три конструктора: по умолчанию (инициализирует поля нулями), параметризованный (принимает "x" и "y") и конструктор копирования.
3. Реализовать геттеры и сеттеры для безопасного доступа к полям.
4. Реализовать метод "Contains": с помощью "std::min" и "std::max" найти левую и правую границы отрезка и проверить условие вхождения числа.
5. Перегрузить оператор "<<" как дружественную функцию ("friend"), чтобы она имела доступ к приватным полям и могла вывести объект в формате "LineSegment[x, y]".
6. В файле "main.cpp" написать вспомогательные функции "ReadDouble" и "ReadInt". В них использовать цикл "while(true)" и обработку ошибок потока ("std::cin.clear()" и "std::cin.ignore()"), чтобы программа не завершалась при вводе некорректных данных.
7. В функции "main" создать объекты класса, используя разные конструкторы, и протестировать метод "Contains" с числом, введенным пользователем.

## Задание 2

### Текст задачи

Добавить к реализованному в первом задании классу "LineSegment" указанные перегруженные операции:
**Унарные операции:**
- "!" - вычислить длину отрезка, результат должен быть типа "double".
- "++" - увеличить координаты границ отрезка на 1 (реализовать префиксную и постфиксную формы).

**Операции приведения типа:**
- "int" (явная) – результатом является целая часть координаты "x".
- "double" (неявная) – результатом является координата "y".

**Бинарные операции:**
- "+ int d" – координаты границ увеличиваются на число "d".
- "> int d" – результат равен "true", если целое число попадает в заданный отрезок, и "false" – в противном случае.

В главной функции "main" показать работу всех функций с дружественным интерфейсом.

### Алгоритм решения

1. В классе объявить методы-операторы.
2. Реализовать "operator!()": вернуть модуль разности координат "std::abs(y_ - x_)".
3. Реализовать префиксный "operator++()": увеличить "x_" и "y_" на 1, вернуть ссылку на текущий объект ("*this").
4. Реализовать постфиксный "operator++(int)": сохранить текущее состояние объекта во временную переменную, увеличить поля, вернуть временную переменную (старое состояние).
5. Реализовать "explicit operator int()": вернуть "static_cast<int>(x_)". Ключевое слово "explicit" запрещает неявное приведение.
6. Реализовать "operator double()": вернуть значение "y_".
7. Реализовать "operator+(int d)": создать и вернуть новый объект "LineSegment", где к обеим координатам прибавлено "d".
8. Реализовать "operator>(int d)": привести "d" к "double" и вернуть результат вызова метода "Contains".
9. В "main.cpp" последовательно продемонстрировать работу каждого оператора, выводя результаты в консоль.
